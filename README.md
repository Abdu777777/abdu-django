# نظام إدارة حلقات تحفيظ القرآن الكريم 📖

مشروع متكامل لإدارة حلقات التحفيظ، تم تطويره باستخدام إطار العمل **Django** ليلبي كافة المتطلبات الأكاديمية والتقنية.

## 🌟 فكرة المشروع
يهدف النظام إلى أتمتة إدارة حلقات تحفيظ القرآن الكريم، حيث يسهل على المعلمين إدارة حلقاتهم، تسجيل طلابهم، متابعة تقدمهم في الحفظ، وتسجيل الحضور والغياب بشكل يومي.

## 🛠 المميزات التقنية (تحقيق شروط المشروع)

### 1. قاعدة البيانات (5 جداول)
تم تصميم قاعدة البيانات بعلاقات منطقية قوية:
- **المعلم (Teacher):** مرتبط بنظام المستخدمين (OneToOne).
- **الحلقة (Halaqa):** مرتبطة بالمعلم (ForeignKey).
- **الطالب (Student):** مرتبط بالحلقة (ForeignKey).
- **سجل التسميع (Progress):** مرتبط بالطالب (ForeignKey).
- **سجل الحضور (Attendance):** مرتبط بالطالب (ForeignKey).

### 2. العمليات الأساسية (CRUD)
تم تطبيق عمليات الإضافة، العرض، التعديل، والحذف لجميع الجداول الأساسية من خلال واجهات النظام:
- إدارة الحلقات.
- إدارة الطلاب.
- تسجيل ومتابعة التسميع.
- تسجيل ومتابعة الحضور والغياب.

### 3. نظام المستخدمين والصلاحيات
- نظام تسجيل دخول وخروج متكامل.
- صفحة لإنشاء حساب معلم جديد.
- حماية كافة الصفحات الحساسة؛ حيث لا يمكن الوصول للبيانات إلا بعد تسجيل الدخول.
- **صلاحيات ذكية:** المعلم يشاهد ويدير فقط الحلقات والطلاب التابعين له.

### 4. الواجهات والتنظيم
- استخدام **Bootstrap 5** مع دعم كامل للغة العربية (RTL).
- تصميم عصري وسهل الاستخدام (Responsive Design).
- تنظيم الكود إلى Apps وملفات مرتبة (Models, Views, Forms, Templates).

## 🚀 كيفية التشغيل
1. تثبيت المتطلبات: `pip install django`
2. تطبيق الهجرات: `python manage.py migrate`
3. تشغيل الخادم: `python manage.py runserver`
